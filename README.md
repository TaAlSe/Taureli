# Taureli — ядро для русских шахмат (таврелей)

Это MVP (минимально жизнеспособный продукт) десктопного приложения для игры в таврели (русские шахматы). На данном этапе реализована только логика ходов основных фигур.

## Архитектура

Проект разделён на три слоя:
- **Core** — независимое ядро (логика фигур, доски, генерация ходов).
- **Data** — (пока пусто, будет для хранения партий).
- **UI** — (будет WPF-интерфейс, пока не реализован).
- **Tests** — юнит-тесты для Core.
- **Demo** — консольная демонстрация возможностей.

## Структура Core

### Папка `Board`
- `ChessBoard.cs` — класс доски 8x8 с методами GetPiece/SetPiece/Clear.

### Папка `Pieces`
- `PieceColor.cs` — enum (White, Black).
- `PieceType.cs` — enum с типами фигур таврелей.
- `Piece.cs` — record (Type, Color) с методом GetDebugCode().
- `PieceFactory.cs` — статический метод для начальной расстановки.

### Папка `Moves`
- `Position.cs` — record struct с координатами (Row, Col), методы FromAlgebraic/ToAlgebraic.
- `Move.cs` — record (From, To, PromotionType).
- `Directions.cs` — статические константы направлений движения (Up, Down, ...) и готовые наборы для ладьи, слона, князя.
- `LinearMoveGenerator.cs` — универсальный метод GetMoves, генерирующий ходы по заданным направлениям.
- `MoveGenerator.cs` — единая точка входа для ходов любой фигуры (использует словарь направлений).

## Как генерируются ходы

1. Фигура стоит на позиции `from` на доске.
2. Вызывается `MoveGenerator.GetMovesForPiece(board, from)`.
3. По типу фигуры из словаря `_directionsMap` берутся направления.
4. `LinearMoveGenerator.GetMoves` проходит по каждому направлению, пока не встретит преграду (свою фигуру — стоп, вражескую — можно взять и стоп).

## Тестирование

Все тесты находятся в проекте `Tests`. Используется xUnit. Покрытие основных сценариев:
- Начальная расстановка.
- Генерация ходов для ладьи, слона, князя на пустой доске и с преградами.
- Преобразование позиций (алгебраическая нотация).

## Как запустить демо

1. Собрать решение.
2. Назначить проект `Demo` запускаемым.
3. Запустить — в консоли увидите доску и списки ходов для фигур.
